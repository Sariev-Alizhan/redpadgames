## How to choose

- **Pick 01 if** the redesign should ride Dustland's success and the studio narrative is "we make masterpiece post-apocalyptic worlds." The Tencent Cloud banner sits inside that world.
- **Pick 02 if** the redesign's job is to **convert enterprise-tier partner traffic** in week one. Trades some game-romance for visible operational gravity.
- **Pick 03 if** the studio wants its **first redesign to win Awwwards** and become the talked-about Kazakh studio site. Highest brand-distinct, highest execution risk.
- **Remix candidates**:
  - **01 + 03**: cinematic Dustland imagery as hero, ink page-turns as inter-section transitions. Possible but doubles motion-language vocabulary — hard to police.
  - **02 + 03**: globe hero (clarity) + ink page-turns into editorial sub-pages (craft). Best of both worlds for a partner site that still wants soul.
  - **02 + 01**: globe hero + dust transitions on the games-portfolio scroll. Most pragmatic; loses some signature edge.
